🌸 AURA — Autocuidado e Bem-estar

O AURA é um aplicativo desenvolvido em Flutter com o objetivo de auxiliar na organização da rotina de autocuidado e promover o bem-estar dos usuários.

A proposta é reunir, em um único lugar, ferramentas para acompanhar hábitos diários, organizar cuidados capilares, monitorar o ciclo menstrual e visualizar o próprio progresso, tornando o autocuidado mais simples, acessível e organizado.

✨ Funcionalidades

- Tela inicial: visão geral das atividades e dos hábitos diários, incluindo acompanhamento de água, sono e humor.
- Cronograma capilar: organização dos tratamentos capilares em um calendário, com categorias diversas.
- Ciclo menstrual: acompanhamento e registro das informações relacionadas ao ciclo menstrual.
- Rotinas: organização das atividades e dos cuidados pessoais.
- Progresso: visualização do acompanhamento e da evolução dos registros realizados no aplicativo.
- Perfil do usuário: gerenciamento das informações pessoais, personalização da foto de perfil e opções de aparência.
- Autenticação: cadastro e login de usuários, incluindo autenticação com Google.

🏗️ Organização do projeto

O projeto utiliza uma organização baseada na separação de responsabilidades, facilitando a manutenção e a evolução do código.

- models: classes responsáveis pela representação dos dados.
- views/pages: telas e interfaces do aplicativo.
- viewmodels: gerenciamento de estados e regras relacionadas às funcionalidades.
- widgets: componentes reutilizáveis da interface.
- services: serviços responsáveis pela comunicação com recursos externos, como Firebase.
- theme: configurações visuais, cores e estilos do aplicativo.

🚀 Como executar o projeto

Pré-requisitos

Antes de iniciar, é necessário ter instalado:

- Flutter SDK;
- Dart SDK;
- Visual Studio Code ou Android Studio;
- Uma configuração válida de projeto no Firebase.

Instalação

1. Clone o repositório:

git clone https://github.com/tarscilla/aura-app.git

2. Acesse a pasta do projeto:

cd aura-app

3. Instale as dependências:

flutter pub get

4. Configure o Firebase para o projeto, incluindo os arquivos de configuração necessários para a plataforma escolhida.

5. Execute o aplicativo:

flutter run
